# Hyper-V SCOM integration tests

Integration tests will import test-sealed artifacts into each supported pre-production SCOM
management group and validate dependencies, discovery, monitoring, overrides, Distributed
Applications, upgrade, and removal. They cannot run against development XML or a production
management group.

The suite remains intentionally empty until the supported SCOM lab, Microsoft verification tools,
test-signing identity, and first evidence-approved Management Pack elements are available.
