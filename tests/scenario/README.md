# Hyper-V SCOM scenario tests

Scenario tests will exercise the public operator journeys in the Management Pack administration
guide: first import, topology verification, creation of separate Discovery and Monitoring override
MPs, tuning-profile adoption, upgrade, recovery, and dependency-safe removal.

Each scenario requires a supported pre-production SCOM management group and repeatable standalone
or clustered Hyper-V fixtures. Production management groups are never scenario-test targets.
