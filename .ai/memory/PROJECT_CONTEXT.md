# Project context

This repository defines a shared Azure Local infrastructure health model for two planned delivery
tracks: a SCOM Management Pack and Azure Monitor Health Models. SquaredUp integrations are optional
visualization layers. The design phase is complete; product implementation has not started.

The documentation is a VitePress site rooted at `docs/` and published beneath the
`/azurelocal-scom-mp/` base path. ADR 0020 records the repository owner's explicit decision to use
VitePress. The site is deployed by GitHub Pages and the central Azure DevOps VitePress template.
